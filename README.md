# برو أند بايت — مينيو إلكتروني (Brew & Bite Digital Menu)

مينيو إلكتروني ثابت بدون سلة ولا طلبات ولا قاعدة بيانات. صفحة واحدة للزباء + لوحة تحكم للمالك، وكل البيانات في ملف `menu-data.json` واحد.

- **الواجهة:** `index.html` + `assets/` — عربية/إنكليزية، بحث، أقسام، ترتيب، تحويل عملة (ل.س/$)، تفاصيل المنتج.
- **اللوحة:** `/admin/` — إدارة المنتجات والأقسام وبيانات المطعم والإعدادات.
- **النشر:** كل تعديلات اللوحة تُحفظ كـ commit عبر GitHub Contents API — أي استضافة ثابتة (GitHub Pages) تكفي.

## الدخول إلى لوحة التحكم

افتح `/admin/`:

- **اسم المستخدم:** `admin`
- **كلمة المرور:** `BrewAndBite2024`

غيّر كلمة المرور فوراً من تبويب **الإعدادات ← تغيير كلمة المرور**.

## تفعيل الحفظ والنشر (مرة واحدة)

1. من GitHub: Settings → Developer settings → Personal access tokens → **Fine-grained token** على هذا المستودع بصلاحية **Contents: Read and write** (أو classic token بصلاحية `repo`).
2. في اللوحة: **الإعدادات ← توكِن النشر** — الصق التوكِن واضغط «حفظ التوكِن». يُخزَّن في متصفحك فقط ولا يُنشر مع الكود.
3. اضغط «التحقق» للتأكد من الصلاحية.

بعد أي تعديل في اللوحة يظهر شريط سفلي: **استعادة** (ترجع آخر نسخة منشورة) أو **حفظ ونشر** (commit واحد بكل التغييرات). صور المنتجات تُرفع مباشرة إلى `img/` بنفس الطريقة.

## البيانات

- `menu-data.json` — كل المينيو والإعدادات. احتفظ بنسخة احتياطية عبر **الإعدادات ← تنزيل نسخة JSON**، واستعِدها بزر «استيراد نسخة».

## الاستضافة

أي استضافة صفحات ثابتة. مع GitHub Pages: Settings → Pages → Source: **Deploy from a branch** → `main` / root.
